## Overview

This is my first solo web project showcasing my coding skills! :)

CosoraAtlas is an interactive web map that aggregates anime, manga and cosplay events across the Nordic and Baltic region. 

Users filter by date, category andcountry, and event organisers submit new entries through a moderated pipeline.

![CosoraAtlas map view](./assets/screenshots/cosoraatlas.png)

## Lessons Learned

- Modelling geospatial data cleanly with PostGIS.
- Clustering hundreds of markers without janky panning.
- Building a lightweight moderation workflow for submissions.
