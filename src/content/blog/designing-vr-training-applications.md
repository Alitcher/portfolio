# Designing VR Training Applications

VR training only earns its keep if the skills transfer to the real world. A pretty
simulation that teaches nothing is just a tech demo. Here is the framework I use.

## Start from the task, not the tech

Before opening Unity I write down the exact real-world procedure, step by step. The
simulation exists to rehearse *that* procedure — every interaction maps to a real one.

## Make it measurable

- Record completion time, mistakes and the order of steps.
- Surface a debrief screen so trainees see what to improve.
- Let instructors replay a session.

## Repeatable scenarios

Randomise the incidental details but keep the learning objective fixed. Trainees
should be able to run the same scenario ten times and improve each time.

## Comfort is a feature

Motion sickness ends a training session instantly. I default to teleport locomotion,
snap turning and a stable horizon, and only add smooth locomotion as an opt-in.

The goal is muscle memory, not novelty.
